# HOUD HONEY Landing Page

نسخة منظمة من صفحة الهبوط الأصلية، جاهزة للنشر على GitHub Pages.

## البنية
- `index.html` — نقطة الدخول فقط.
- `css/main.css` — تنسيقات الصفحة.
- `js/config.js` — إعدادات الموقع، ومنها رقم WhatsApp.
- `js/app.js` — منطق وواجهة التطبيق المستخرجين من النسخة الأصلية.
- `images/` — الصور.

## قبل النشر
غيّر رقم WhatsApp في `js/config.js` إلى الرقم الحقيقي، بصيغة دولية بدون `+` أو مسافات.

## GitHub Pages
المشروع Static ولا يحتاج إلى Build أو Node.js. فعّل Pages من فرع `main` والمجلد `/ (root)`.
